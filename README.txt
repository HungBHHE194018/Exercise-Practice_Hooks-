MINI TASK MANAGER - HƯỚNG DẪN CHẠY

1. Giải nén file ZIP.
2. Mở thư mục MiniTaskManager_Final bằng VS Code.
3. Mở Terminal tại thư mục đó.
4. Chạy:
   npm install

5. Sau khi cài xong chạy:
   npm run dev

6. Mở đường link Vite hiện trong Terminal, thường là:
   http://localhost:5173

BÀI CÓ:
- React Context: ThemeContext.jsx
- Custom Hook: useLocalStorage.js
- Thêm công việc
- Tick hoàn thành
- Xóa công việc
- Lọc Tất cả / Chưa làm / Hoàn thành
- Tìm kiếm
- Thống kê Tổng / Chưa làm / Hoàn thành
- Dark / Light
- Lưu dữ liệu bằng LocalStorage

Kết quả ban đầu được thiết kế theo ảnh yêu cầu:
Tổng: 5 | Chưa làm: 3 | Hoàn thành: 2
